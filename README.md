# kellenhart.com

Personal blog and site. Plain HTML + CSS, hosted on GitHub Pages.

## Local dev

```
make serve
```

Opens at [http://localhost:8000](http://localhost:8000).

## Structure

```
index.html              # Homepage with bio and blog listing
blog/                   # Blog posts (each post is a directory with index.html)
css/main.css            # Styles
CNAME                   # Custom domain config
```
